## [Unreleased]

### Added

- Project brief and the full documentation set (product, project, code, quality, ops).
- ADR-0001..0004 — initial architecture, OCR engine, translation abstraction, and the capture/coordinate model.
- Frontend scaffold: Vite 7 + React 19 + TypeScript (strict) + Tailwind v4, with one entry per window.
- `coords.ts` — the single CSS↔physical conversion boundary, covered by 49 tests across a grid of scale factors
  and virtual-desktop origins, including negative origins and mixed-DPI layouts.
- `fitText.ts` — the shrink → wrap → clip fitting ladder for in-place translations, with an injectable text
  measurer so it is testable without a DOM.
- `ipc.ts` — the complete typed IPC surface, enforced by eslint as the only module allowed to call Tauri.
- Capture overlay, in-place result layer, result panel, and settings window.
- MIT LICENSE.
- Rust core (`src-tauri/`): tray icon and menu, single-instance guard, global hotkey with live rebinding,
  virtual-desktop capture via GDI `BitBlt`, in-memory cropping, the `otr://` frame protocol, settings persistence
  with per-field recovery, and structured logging with a `Redacted` type that makes captured content
  un-loggable by construction.
- `geometry.rs` — the Rust twin of `coords.ts`, including crops taken from a negative-origin virtual desktop.
- Target language is detected from the Windows display language on first run, with no settings file.
- An app icon, generated by a committed script so it can be regenerated rather than hand-maintained.
- **OCR (M2).** The crop now becomes text: a conditional pre-processing ladder (grayscale → Lanczos-3 upscale for
  text under 20 px → contrast normalize → adaptive threshold when contrast is low), the `OcrEngine` trait, the
  `Windows.Media.Ocr` implementation, and line assembly that groups lines into paragraphs so a translator sees
  sentences rather than fragments.
- `recognize_region` — OCR with no translation and no network. The source text the overlay falls back to when a
  provider fails.
- Recognized lines carry their bounding box in virtual-desktop space, so the in-place overlay can position them.
- A missing OCR language pack is reported by name with a link to the Windows language setting, rather than as a
  generic failure (FR-34).
- Six fixture tests against the real OCR engine. The fixtures are rendered with GDI at test time rather than
  committed as images, so bounding-box assertions check against measured ink
  ([ADR-0005](docs/architecture/adr/0005-ocr-test-fixtures-are-rendered.md)).

### Changed

- IPC contract gained `get_panel_result`, `close_panel`, and the `otr://result` event — the contract never said
  how the result panel receives a result.
- `docs/engineering/project-structure.md` corrected to the shape actually built (window HTML at the repo root,
  Tailwind v4's CSS-first config, `types.ts` until `ts-rs` generation lands).
- **`confidence` is now nullable** everywhere in the IPC contract. `Windows.Media.Ocr` reports no confidence at
  all, so the v1 engine returns `null` rather than a fabricated number, and the UI treats unknown as unknown —
  never as low ([TD-09](docs/project/tech-debt.md)).
- FR-31, FR-32 and FR-33 reworded to what the engine actually does: the ladder is only shown to be *no worse*
  (TD-11), confidence may be absent (TD-09), and "source language detection" is recognizer selection rather than
  detection (TD-10).
- OCR fixtures are rendered at test time instead of committed as PNGs, so `src-tauri/fixtures/` is not created
  ([ADR-0005](docs/architecture/adr/0005-ocr-test-fixtures-are-rendered.md)).

### Fixed

- `clampRectToBounds` now collapses both dimensions when rects overlap on only one axis. It previously returned
  the surviving axis's size, which a caller could read as a real intersection.
- Quit from the tray menu did nothing. `prevent_exit()` was called for every exit request, including the user's
  own Quit, leaving a tray icon that could not be dismissed. Only window-close-driven exits are prevented now.
